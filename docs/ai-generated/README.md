# AI 生成文档目录

本目录用于保存项目开发过程中由 AI 辅助生成、并经过人工确认的需求、设计、实施与验收文档。

## 文档约定

- 文档必须以当前笔试题和已确认需求为依据，不把设想写成已实现功能。
- 影响开发范围、接口或数据结构的变更，应同步更新技术方案。
- 实际实现与方案不一致时，以代码为准，并在方案的“决策与变更记录”中说明。
- 面向最终交付的操作说明仍应整理到仓库根目录 `README.md`；本目录保存更详细的过程文档。

## 当前文档

- [技术方案.md](./技术方案.md)：项目范围、架构、数据库、实体、接口、测试与交付设计。
- [多阶段实施方案.md](./多阶段实施方案.md)：从当前空代码基线到最终验收的分阶段开发计划、边界和通过标准。
